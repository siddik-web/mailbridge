# 02 — Server Profiles and Security

Design and implement server profiles with validated hostname, port, encryption mode, username, and encrypted secret storage. Define and implement a documented SSRF/DNS-rebinding policy, strict TLS certificate/hostname validation, connection timeouts, safe errors, REST permission checks, and secret redaction. Prefer authenticated encryption and document key management and rotation constraints. Add tests for authorization, invalid values, TLS failures, secret leakage, and private/loopback IP policy. Do not begin migration jobs in this slice.
