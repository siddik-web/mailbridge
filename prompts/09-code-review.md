# 09 — Code Review

Perform a read-only review of the current diff. Focus on correctness, WordPress conventions, authorization, secret handling, SQL safety, SSRF/TLS, IMAP protocol edge cases, idempotency, retry behavior, concurrency, accessibility, tests, maintainability, and scope. Report findings with severity and file/line references. Do not praise style at the expense of risks. Do not edit files. If no findings are found, state what was reviewed and what could not be verified.
