# 08 — Release Candidate Gate

Follow `docs/RELEASE_CHECKLIST.md`. Inspect clean install, upgrade behavior, dependencies/licenses, plugin packaging, supported PHP/WordPress versions, test matrix, security findings, documentation, and changelog. Run available quality gates and report exact commands/results, including tests not run and why. Do not call this production-ready if any required security/data-integrity evidence is missing or critical/high findings remain unresolved.
