# 06 — Admin Dashboard

Build the React/TypeScript admin UI using the repository's chosen WordPress build toolchain. First verify REST contracts and existing dependencies. Add accessible profile forms, migration confirmation, progress/status, pause/resume where supported, sanitized error states, and reports. Do not store secrets in browser storage or log them. Include loading, empty, validation, and failure states. Add frontend tests and Playwright smoke coverage if the environment supports it; report checks actually run.
