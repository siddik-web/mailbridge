Create or improve tests for the assigned feature. Cover success, validation, authorization, failure, restart/resume, concurrency, and security boundaries as relevant. Use disposable fixtures and controlled IMAP servers only. Run available checks and report exact commands, test counts, failures, and checks not run. Do not claim success without output evidence.
